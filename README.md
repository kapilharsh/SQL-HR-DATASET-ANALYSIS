# SQL-HR-DATASET-ANALYSIS
Exploratory data analysis of an HR dataset to uncover trends in employee attrition, performance, and satisfaction.


HR Dataset Analysis
📌 Overview

This project analyzes an HR dataset to explore trends in employee attrition, satisfaction, performance, and workforce demographics. The goal is to uncover actionable insights that can support HR decision-making, such as identifying factors that drive employee turnover.

🎯 Objectives
Explore key HR metrics (attrition, tenure, salary, satisfaction, performance)
Identify patterns and correlations that influence employee attrition
Visualize trends across departments, job roles, and demographics
Provide data-driven recommendations for HR strategy


📂 Dataset
Size: [MORE THAN 1000]
Key columns: Employee ID, Age, Department, Job Role, Monthly Income, Attrition, Years at Company, Job Satisfaction, etc.
